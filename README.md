# Trabalho-do-bruno

# Primeira Parte ( KEVIN )
Realizado o início do programa, onde é requisitado 2 valores inteiros ao usuário, a fim de guarda-los e utiliza-los posteriormente nas *FUNÇÕES*

# Segunda Parte ( DAVI )
Definido as opções de operações matemáticas a ser realizada pelo programa

# Terceira Parte ( RAFAEL )
Declarada as funções matemáticas para cada opção criada na segunda parte do programa. Aqui serão realizados os devidos cálculos com base nos valores fornecidos pelo usuário anteriormente
